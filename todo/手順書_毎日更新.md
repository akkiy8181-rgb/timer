# そうまのやることリスト — 毎日更新手順書

**対象：あき**　｜　所要時間：約3分　｜　必要なもの：スマホまたはPC

---

## 全体の仕組み

```
Claude がHTMLを生成
      ↓
GitHub の index.html を差し替える（ここだけやればOK）
      ↓
Vercel が自動でデプロイ（約30秒）
      ↓
固定URLで最新リストが見られる
```

---

## 【初回だけ】セットアップ（所要：15〜20分）

### ステップ1：GitHubアカウントを作る

1. https://github.com を開く
2. 右上「Sign up」→ メールアドレス・パスワードを設定
3. メール認証を完了させる

### ステップ2：このリポジトリをフォークする

1. https://github.com/akkiy8181-rgb/timer を開く
2. 右上の「Fork」ボタンをクリック
3. 「Create fork」をクリック
4. 自分のアカウントにコピーされる（例：`あきのアカウント名/timer`）

### ステップ3：Vercelアカウントを作る

1. https://vercel.com を開く
2. 「Start Deploying」→「Continue with GitHub」でGitHubと連携
3. Vercel が GitHub へのアクセスを求めるので「Authorize」をクリック

### ステップ4：Vercelにデプロイする

1. Vercel の「Add New Project」をクリック
2. `timer` リポジトリを選ぶ
3. **Root Directory** の欄に `todo` と入力する（重要！）
4. 他はそのまま「Deploy」をクリック
5. 数分待つと **固定URL** が表示される（例：`https://timer-xxx.vercel.app`）
6. そのURLをメモ帳やメモアプリに保存しておく

---

## 【毎日の作業】HTMLを差し替える（所要：約3分）

### ステップ1：Claudeに新しいHTMLを作ってもらう

Claudeに話しかける例：
```
そうまの今日のやることリストを作って。
国語：〇〇
算数：〇〇
（内容を伝える）
HTMLファイルで出して。
```

Claudeが `todo_print_YYYYMMDD.html` の内容を出してくれる。

### ステップ2：HTMLの中身をコピーする

1. Claudeが出したHTMLの内容を**全部選択してコピー**する
   - Mac：Command + A → Command + C
   - Windows：Ctrl + A → Ctrl + C

### ステップ3：GitHubのファイルを差し替える

1. https://github.com/（あきのアカウント名）/timer を開く
2. `todo` フォルダをクリック
3. `index.html` をクリック
4. 右上の**鉛筆マーク（✏️ Edit this file）**をクリック
5. 画面の中の文字を全部選択して削除（Ctrl+A → Delete）
6. コピーしたHTMLを貼り付け（Ctrl+V）
7. 画面右上の緑の「Commit changes」ボタンをクリック
8. そのまま「Commit changes」をクリック（コメントは空でOK）

### ステップ4：Vercelの自動デプロイを待つ

- 30秒〜1分で固定URLに反映される
- https://vercel.com のダッシュボードで進捗が見られる

### ステップ5：スマホで確認・印刷

1. 固定URLを開く
2. 確認できたら印刷
   - iPhone：共有ボタン→「プリント」
   - Android：メニュー→「印刷」

---

## よくあるトラブル

| 症状 | 対処法 |
|------|--------|
| Vercelに反映されない | Vercelのダッシュボードを開いてデプロイが「Building」になっているか確認。エラーが出ていたらスクリーンショットをClaudeに見せる |
| GitHubにログインできない | パスワードリセットメールを送る |
| 固定URLを忘れた | https://vercel.com を開くとプロジェクト一覧にURLが表示されている |
| 印刷がうまくいかない | ブラウザの印刷設定で「背景のグラフィック」をオンにする |
